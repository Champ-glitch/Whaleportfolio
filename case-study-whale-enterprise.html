CASE STUDY

WHALE_SYS: A Telegram-Native Payment & Savings System

How a solo developer built a full M-Pesa payment and personal finance system that runs entirely inside a Telegram chat — deployed and maintained end to end from an Android phone.

LIVE IN PRODUCTION

Visit Live Site →
The Problem

Manual money tracking doesn't scale.

As a solo developer and trader, I needed a way to collect M-Pesa payments, track my own spending, and build savings discipline — without paying for a fintech SaaS product or maintaining a separate app.

Manual M-Pesa tracking meant money in and money out lived in my head, savings never got set aside consistently, and there was no single source of truth for my finances.

The Solution

A finance system that lives inside chat.

I built WHALE_SYS: a Telegram-native payment and personal finance system that runs entirely through chat. It generates M-Pesa payment links and STK push requests, and — the core feature — automatically splits every incoming deposit 60/40 into a Main spending account and a Savings account the moment it lands, whether it came from a shared payment link, a self-sent STK push, or a manual Till deposit with no reference at all.

No manual step required to start saving; the discipline is built into the money's arrival, not left to willpower afterward.

On top of that: category-tagged expense tracking, a weekly savings report, a visual balance dashboard with goal progress, and a crypto off-ramp via Pretium's agent rails for converting stablecoins back to fiat.

How It Works

Under the hood.

Next.js 14 serverless functions on Vercel handle all logic; Vercel KV (Redis) is the entire data layer.

PayHero integration handles M-Pesa STK push and C2B webhook callbacks.

Groq (Llama 3.3) powers a natural-language command layer, so I can type "send 500 to john" instead of memorizing syntax — with strict validation ensuring the AI can suggest an action but never directly move money.

A real MCP (Model Context Protocol) server integration with Pretium handles crypto-to-fiat payouts.

Built and deployed entirely from an Android phone using Termux — no computer involved at any point.

Impact

Savings, automated.

What used to be a mental tally of "how much did I make, how much did I spend, did I save anything" is now automatic and enforced at the moment money arrives. Every deposit is already split before I even think about it.
